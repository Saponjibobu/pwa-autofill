# PWA Autofill

Aplikasi web kecil untuk membuka form Pre Work Assessment yang sudah terisi otomatis.
NPP dan No Polisi diisi di HP dan hanya disimpan di HP (localStorage), tidak ada di repo ini.

Install di Android: buka https://saponjibobu.github.io/pwa-autofill/ di Chrome, lalu menu ⋮ → Instal aplikasi.
